## Welkom! 👋

Bedankt dat je deze front-end programmeeruitdaging bekijkt.

De uitdagingen van [Frontend Mentor](https://www.frontendmentor.io) helpen je je programmeervaardigheden te verbeteren door realistische projecten te bouwen.

**Om deze uitdaging aan te gaan, heb je een goede kennis van HTML en CSS nodig, evenals basiskennis van JavaScript.**

## De uitdaging

Jouw uitdaging is een landingspagina te bouwen en deze zo goed mogelijk te laten aansluiten bij het ontwerp.

Deze uitdaging richt zich voornamelijk op HTML en CSS. Er zit soms een klein beetje JavaScript in voor de mobiele navigatieschakelaar. Maar je kunt er ook voor kiezen om dit zonder JavaScript te doen!

Je kunt alle tools gebruiken die je wilt om de uitdaging te voltooien. Dus als je iets hebt waarmee je graag wilt oefenen, ga je gang.

Je gebruikers moeten het volgende kunnen doen:

- De optimale lay-out van de site zien, afhankelijk van de schermgrootte van hun apparaat
- Hover-effecten zien voor alle interactieve elementen op de pagina

### Heb je hulp nodig bij de uitdaging?

[Word lid van de frontendmentor community](https://www.frontendmentor.io/community) en stel vragen in het **#help**-kanaal.

## Waar vind je alles?

Het is jouw taak om het project uit te werken volgens de ontwerpen in de map `/design`. Je vindt daar zowel een mobiele als een desktopversie van het ontwerp.

De ontwerpen zijn in het statische JPG-formaat. Omdat het om JPG’s gaat, moet je zelf je gezond verstand gebruiken bij het bepalen van stijlen zoals `font-size`, `padding` en `margin`.

Als je het Figma-ontwerpbestand wilt gebruiken om het ontwerp in meer detail te bekijken, kun je je [aanmelden als PRO-lid](https://www.frontendmentor.io/pro).

Je vindt alle benodigde bestanden in de map `/images`. De bestanden zijn al geoptimaliseerd.

Er is ook een `style-guide.md`-bestand met de informatie die je nodig hebt, zoals het kleurenpalet en de lettertypen.

## Gebruik van AI-codeerassistenten

We hebben twee bestanden toegevoegd om je te helpen als je tijdens het werken aan deze uitdaging gebruikmaakt van AI-codeerassistenten (zoals Claude, GitHub Copilot, Cursor, enz.):

- `AGENTS.md` - Bevat gedetailleerde instructies voor AI-assistenten over hoe ze je bij deze uitdaging kunnen helpen. Het is afgestemd op de moeilijkheidsgraad van deze uitdaging, zodat de AI begeleiding biedt die past bij jouw leerniveau — met meer ondersteuning bij uitdagingen voor beginners en meer aanmoediging tot zelfstandigheid bij uitdagingen voor gevorderden.
- `CLAUDE.md` - Een verwijzingsbestand dat op Claude gebaseerde tools naar de instructies in AGENTS.md leidt.

**Hoe je ze gebruikt:** Je hoeft helemaal niets te doen! Deze bestanden worden automatisch herkend door de meeste AI-codeertools. De AI leest ze en past zijn gedrag aan om een betere leerpartner te worden – hij begeleidt je naar oplossingen in plaats van je alleen maar de antwoorden te geven.

**Opmerking:** Deze bestanden zijn bedoeld om je te helpen *leren*, niet om het werk voor je te doen. De AI is geprogrammeerd om vragen te stellen, hints te geven en concepten uit te leggen, in plaats van complete oplossingen te schrijven.

## Je project opzetten

Gebruik gerust elke workflow waarmee je je prettig voelt. Hieronder vind je een voorgesteld proces, maar voel je niet verplicht om deze stappen te volgen:

1. Initialiseer je project als een openbare repository op [GitHub](https://github.com/). Door een repository aan te maken, kun je je code gemakkelijker delen met de community als je hulp nodig hebt. Als je niet zeker weet hoe je dit moet doen, [lees dan deze Try Git-handleiding eens door](https://try.github.io/).
2. Configureer je repository zodat je code op een webadres wordt gepubliceerd. Dit is ook handig als je tijdens een uitdaging hulp nodig hebt, omdat je dan de URL van je project kunt delen samen met de URL van je repository. Er zijn verschillende manieren om dit te doen; hieronder geven we enkele aanbevelingen.
3. Bekijk de ontwerpen om te beginnen met het plannen van hoe je het project gaat aanpakken. Deze stap is cruciaal om je te helpen vooruit te denken over CSS-klassen, zodat je herbruikbare stijlen kunt maken.
4. Schrijf een blog over je ervaringen bij het bouwen van je project. Door te schrijven over je werkwijze en technische keuzes, en je code toe te lichten, kun je wat je hebt geleerd op een briljante manier verankeren. Goede platforms om op te schrijven zijn [dev.to](https://dev.to/), [Hashnode](https://hashnode.com/) en [CodeNewbie](https://community.codenewbie.org/).

We bieden sjablonen aan om je te helpen je oplossing te delen zodra je deze op het platform hebt ingediend. Pas ze gerust aan en stel specifieke vragen als je op zoek bent naar feedback.

Hoe specifieker je vragen zijn, hoe groter de kans dat een ander lid van de community je feedback geeft.
